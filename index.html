Controls and shortcuts

Main buttons

  • File — new, import, export/download, save in browser, copy source, rename.
  • Run or Ctrl+Enter — run current code.
  • Stop — stop a running program; Back returns from the terminal to the editor.
  • Fold all / Unfold all — collapse or expand code blocks.

Mouse and caret

  • Click code to place the caret.
  • Drag to select text; Shift+click extends the selection.
  • Double-click selects a word; triple-click selects a line.
  • Click a line number to select the line. Click the gutter triangle to fold/unfold a block.
  • Alt+click adds/removes an extra caret. Existing extra carets remain while Alt is held.
  • Alt+Shift+drag adds or extends a secondary selection. Hold Alt while using arrows to keep extra carets active; add Ctrl to move by words while selecting.

Editor keyboard shortcuts

  • Ctrl+F — find; selected code is inserted into the search field.
  • Ctrl+R — find and replace; selected code is inserted as the search.
  • Ctrl+G — go to line; starts with the current caret line selected.
  • Enter — newline with automatic indentation.
  • Tab — indent; Shift+Tab — unindent.
  • Ctrl+/ — toggle line comments.
  • Ctrl+Space — autocomplete suggestions.
  • Ctrl+Z — undo; Ctrl+Y or Ctrl+Shift+Z — redo.
  • Ctrl+A — select all; Ctrl+C/X/V — copy/cut/paste.
  • Arrow keys move the caret; Shift+arrows select; Ctrl+left/right moves by word.
  • Home/End — line start/end; Ctrl+Home/End — document start/end.
  • Ctrl+Shift+[ — fold current block; Ctrl+Shift+] — unfold.
  • Escape — close suggestions or the find bar.

Find and replace

  • Aa toggles case-sensitive matching.
  • .* treats the search as a JavaScript regular expression. Invalid expressions turn the search field red.
  • All matches are highlighted; the current match is red. Use ↑/↓ or Enter/Shift+Enter to navigate.
  • Replace replaces the current match; Replace all replaces every match.

Code features

  • Syntax coloring, matching bracket highlights, code folding, autocomplete, and parameter hints.
  • Unused declarations and unreachable sections are marked in the editor.
  • Extra carets allow typing, paste, Backspace, and Delete at multiple positions.

Terminal JavaScript API

  • print(value), println(value), write(value) — output text.
  • input(prompt) — read terminal input.
  • clear() — clear terminal output.
  • sleep(ms) — asynchronously wait for milliseconds; top-level await is supported.
  • onKey(callback) — listen for key events; returns an unsubscribe function.
  • exit() — stop the program; console.log/warn/error also write to the terminal.
  • Extended Math helpers include clamp, lerp, randInt, mean, gcd and more.
